# 提示词

## v1

请先说明计算思路和三种语言各自的性能关键，再给出 Python、C、Rust 实现和统一的 Python 基准框架。

输入：两个长度为 n 的 float64 向量 a、b，n 为非负整数。三版读取同一对小端二进制向量，正式规模为 10000、100000、1000000。

输出：dot(a, b) 返回 float64 点积标量。外层框架报告本次点积耗时与校验和，以 Python 基准核对，相对误差不超过 1e-9。

约束：只用标准库和原生语法，不使用第三方 BLAS、NumPy 或 Numba。C 用 GCC -O2，Rust 用 Cargo --release。数据读取和进程启动在计时前完成，外层 Python 以 perf_counter 计时。预热 3 轮，正式 10 轮分成两组 5 轮并报告中位数。循环须持续消费各次结果。每轮只计算一次点积。

示例：[1,2,3] · [4,5,6] = 32。

## v2

请先说明计算思路和三种语言各自的性能关键，再给出 Python、C、Rust 实现和统一的 Python 基准框架。

输入：两个长度为 n 的 float64 向量 a、b，n 为非负整数。三版读取同一对小端二进制向量，正式规模为 10000、100000、1000000。

输出：dot(a, b) 返回 float64 点积标量。外层框架报告本次点积耗时与校验和，以 Python 基准核对，相对误差不超过 1e-9。

约束：只用标准库和原生语法，不使用第三方 BLAS、NumPy 或 Numba。C 用 GCC -O2，Rust 用 Cargo --release。数据读取和进程启动在计时前完成，外层 Python 以 perf_counter 计时。预热 3 轮，正式 10 轮分成两组 5 轮并报告中位数。循环须持续消费各次结果。每轮连续计算一批点积，同一语言和规模的批量固定，用本轮耗时除以批量。

示例：[1,2,3] · [4,5,6] = 32。

## 修改理由

只改变每轮点积的调用次数和相应的单次耗时换算。常驻进程仍需经管道接收指令并回复。批处理让每轮固定的通信成本由多次计算分摊，并维持相同的预热、取样及误差标准。

## 追加测试指令

保持三版边界语义一致。请编写仅用标准库的 test_dot.py，对三个实际可执行入口分别运行 n=0、n=1、长度不匹配、全零向量和含 NaN 输入五个用例。空向量与全零返回 0.0，单元素返回乘积，长度不匹配报错并以非零状态退出，NaN 传播。
